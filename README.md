# Choreo Lab

## Overview
One of the biggest challenges in learning dance choreography from online videos is figuring out where the 8-counts are in the dance. Choreo Lab solves this problem through beat detection AI models. Upload a dance video and Choreo Lab will make it easier to break down and learn with AI-detected counts, custom looping/speed, mirroring, and more! 

Try out Choreo Lab here: [Production Deployment](http://18.237.24.57:5173/)

## Tech Stack
- Frontend: React/Vite
- Backend: Flask/Python
- Database: Amazon DynamoDB
- Object Storage: Amazon S3
- Message Queue: Amazon SQS
- Background Workers: AWS Lambda
- Auth & Rate Limiting: Redis
- Containerization: Docker
- Deployment: AWS EC2
